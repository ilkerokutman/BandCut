The universal macOS executable is built from these unmodified sources with:

  macos/build_ffmpeg.sh

The build disables GPL, nonfree, and version 3 components. It enables only the
file protocol, WAV demuxing, PCM decoders, LAME MP3 encoding, MP3 muxing, and
audio resampling required by BandCut.
